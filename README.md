# Titanic Passenger Data | Python EDA

> A Jupyter notebook for exploring Titanic passenger records.

**Stack:** Python · Pandas · Matplotlib · Seaborn · Jupyter

## Project
The notebook loads `train.csv` and explores the Titanic dataset. It is a data analysis exercise, not a deployed prediction service.

## Repository contents
- [Analysis notebook](Titanic-Data-Analysis.ipynb)
- [License](LICENSE)

## Getting started
1. Open the notebook in Jupyter or Google Colab.
2. Supply the Titanic training data as `train.csv`.
3. Install the Python libraries imported by the notebook.
4. Run cells in order.
